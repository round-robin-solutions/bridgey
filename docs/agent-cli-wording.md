# Agent devices: shared wording

The words for agent permissions on all three surfaces: the phone's device page, the Mac's agents view and
`bridgey grants`. Change them here first, then in every place. No em dashes.

## Page and tabs

| Key | English | Russian |
| --- | --- | --- |
| page | Devices and permissions | Устройства и разрешения |
| section | What this agent can do | Что может этот агент |
| tab.permissions | Permissions | Разрешения |
| tab.activity | Activity | Действия |
| agent.badge | Agent | Агент |
| agent.subtitle | Command-line agent on %1$s | Агент командной строки на %1$s |
| mac.section | Agents on %1$s | Агенты на %1$s |
| mac.note | Permissions live on the phone. Changes here apply there. | Разрешения хранятся на телефоне. Изменения здесь применяются там. |
| export | Export activity | Экспортировать действия |
| clear | Clear activity | Очистить действия |
| empty | Nothing yet | Пока ничего |

## Grants

| Grant | English | Detail (English) | Russian | Detail (Russian) |
| --- | --- | --- | --- | --- |
| `files` | Send you files | To Download/Bridgey/%1$s | Отправлять вам файлы | В Download/Bridgey/%1$s |
| `clipboard` | Set your clipboard | Text it copies lands on this phone | Менять ваш буфер обмена | Скопированный им текст попадает на этот телефон |
| `clipboard_request` | Ask for your clipboard | You tap Send each time | Запрашивать ваш буфер обмена | Каждый раз вы нажимаете «Отправить» |
| `notify` | Send you notifications | In Agent messages | Присылать вам уведомления | В канале «Сообщения агентов» |
| `ask` | Ask you questions | In Agent questions, with answer buttons | Задавать вам вопросы | В канале «Вопросы агентов», с кнопками ответа |
| `ring` | Ring this phone | Stops by itself after 60 seconds | Звонить на этот телефон | Сам замолкает через 60 секунд |
| `battery` | See battery | Level and charging | Видеть заряд батареи | Уровень и зарядка |
| `codes` | Read codes | One-time codes your Mac finds in messages and mail | Читать коды | Одноразовые коды, которые Mac находит в сообщениях и почте |
| `notifications` | Read your notifications | Not available yet | Читать ваши уведомления | Пока недоступно |
